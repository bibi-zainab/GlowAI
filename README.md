# ✨ GlowAI

AI Powered Skin Health Assistant built using Streamlit + Gemini AI.

## 🚀 Features

- AI Skin Analysis
- Personalized Skincare Recommendations
- AI Chat Assistant
- Skin Health Score
- Wellness Dashboard
- PDF Report Export

## 🛠 Tech Stack

- Python
- Streamlit
- Gemini API
- Plotly
- ReportLab

## 📦 Installation

```bash
pip install -r requirements.txt
```

## ▶ Run App

```bash
streamlit run app.py
```

## 🔐 Environment Variables

Create `.env` file:

```env
GEMINI_API_KEY=your_api_key
``
